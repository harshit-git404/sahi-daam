# Sahi Daam — Experiment Lab Results

This directory contains deterministic, controlled pricing scenario simulation results generated by the Sahi Daam **Experiment Lab**.

## Purpose & Scope
The Experiment Lab provides repeatable, transparent pricing simulations designed to demonstrate:
1. Complete transport-aware cost-basis construction.
2. Safe provisional fallback when transport information is unconfigured or unavailable.
3. Adaptive community reconciliation when independent reports reach or exceed the sample threshold ($\ge 10$ reports).
4. Preservation of cost-basis baseline ranges when community samples are insufficient ($< 10$ reports).
5. Exclusion of flagged duplicates from the independent sample count.
6. The impact of freshness adjustments (₹/kg deductions).
7. Traceable, step-by-step mathematical substitutions from actual computation outputs.

> **Disclaimer:** All scenarios use deterministic mock fixtures and simulated inputs. These experiments do not represent live market transactions, do not prove patentability, and are clearly labeled as mock/simulated records.

## Directory Structure
```text
experiments/
└── scenario_results/
    ├── README.md               # This documentation
    ├── manifest.json           # Global index of all executed experiment runs
    ├── EXPERIMENT_REPORT.md    # Comprehensive human-readable report & summary table
    ├── transport_available/    # Scenario A: Full transport-aware pricing
    │   ├── run_<id>.json       # Complete self-contained JSON evidence
    │   └── summary_<id>.json   # Compact run summary
    ├── transport_unavailable/  # Scenario B: Provisional fallback
    ├── community_low/          # Scenario C: Reconciled with lower community median
    ├── community_high/         # Scenario D: Reconciled with higher community median
    ├── insufficient_community/ # Scenario E: Sample < 10, alpha = 0.0
    ├── duplicate_reports/      # Scenario F: Duplicate flags preserve alpha = 0.0
    ├── freshness_adjustment/   # Scenario G: Quality deduction comparison (G1 vs G2)
    └── combined_*/             # Combinations (transport + community, missing wholesale, etc.)
```

## How to Inspect & Reproduce
1. **Via Web Interface:**
   - Launch the Sahi Daam frontend (`npm run dev`) and backend (`uvicorn backend.main:app`).
   - Open **Experiment Lab** from the side drawer or navigation menu.
   - Select any scenario, view the input preview, click **Run Experiment**, and inspect the step-by-step mathematical calculations rendered **above** the actual output.
2. **Via Backend CLI / Tests:**
   - Run the dedicated test suite:
     ```bash
     python -m unittest backend/tests/test_experiment_service.py -v
     ```
3. **Via API:**
   - List scenarios: `GET /api/experiments/scenarios`
   - Run scenario: `POST /api/experiments/run/{scenario_id}`
   - Retrieve run evidence: `GET /api/experiments/runs/{run_id}`
   - Export evidence JSON: `GET /api/experiments/runs/{run_id}/export`
