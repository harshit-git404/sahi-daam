# Sensor Placement Specification

## Optical Camera
- **Mounting:** Tabletop fixed rig positioned vertically downward at 45cm distance above lot container.
- **Field of View:** Encompasses full 30cm x 20cm inspection aperture.
- **Lighting:** Controlled indoor diffuse LED lighting (ambient luminance 110-140 lux equivalent).

## Stratum Placement (Physical Protocol Design)
- **Stratum S0 (Surface):** Top produce layer directly exposed to ambient air.
- **Stratum S1 (Sub-surface):** Produce units situated immediately beneath top layer (depth 4-7 cm).
- **Stratum S2 (Mid-depth):** Center core layer (depth 8-12 cm).
- **Stratum S3 (Deep stratum):** Lower produce tier (depth 13-17 cm).
- **Stratum S4 (Bottom stratum):** Base tier in contact with container bottom (depth 18-22 cm).

*Note:* Thermal probe placement at strata S0–S4 requires physical thermocouple array integration. Currently marked UNMEASURED.
