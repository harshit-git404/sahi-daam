# Contributing to Sahi Daam

## Branch Naming Convention
Please use the following prefixes for your branches:
- `sai/data-*`
- `navneet/ml-*`
- `abhiram/pricing-*`

## Workflow
- Do not push directly to `main`.
- Create your feature branch, push to origin, and open a Pull Request into `main`.
- Request reviews from the team before merging.
