# Demo Fallback Guide

If the live Gemini API or data.gov.in Agmarknet API fails during a hackathon demo presentation due to rate limits or connectivity issues, follow these instructions to use the pre-verified Golden Demo Case.

## Golden Demo Case Assets
Located in `backend/tests/golden_case/`:
- `tomato.jpg`: A test image of a tomato.
- `golden_response.json`: The expected, verified `/scan-produce` output for this image.

## How to use the Fallback during a Live Demo

If you scan an item and get an error, or if the "data_confidence" falls back unexpectedly:
1. Explain to the judges: *"We hit a rate limit on the live government API / Gemini API, but here is what the exact output looks like when it succeeds."*
2. Open `backend/tests/golden_case/golden_response.json` on the screen.
3. Show the judges the structured response:
   - **Quality Analysis**: Point out `freshness_percent` and `freshness_note` which were generated by Gemini.
   - **Live Mandi Price**: Point out `wholesale_price` and `price_source: "live_local"` showing it successfully pulled data from Katpadi (Vellore).
   - **Haggle Phrases**: Explain that the engine calculated the fair price range and returned dynamic bargaining phrases (under `hagglePhrases`).

This ensures you can still prove the integration works end-to-end even if the 3rd party APIs are temporarily down during your 5-minute pitch!
